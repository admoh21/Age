# Telegram Group Creator Bot (صانع مجموعات تيليجرام)

هذا البوت يسمح للمستخدمين بإدارة حسابات تيليجرام متعددة وإنشاء مجموعات (قروبات) بشكل تلقائي.

## الميزات

- **واجهة بوت سهلة:** يتم التحكم في كل شيء من خلال بوت تيليجرام بواجهة أزرار بسيطة.
- **دعم متعدد للحسابات:** يمكن لأي مستخدم إضافة وإدارة عدة حسابات تيليجرام.
- **إنشاء مجموعات تلقائي:** يقوم بإنشاء مجموعات، تسميتها، إرسال رسائل أولية، وتحويلها إلى مجموعات خارقة.
- **آمن:** يتم حفظ جلسات تسجيل الدخول بشكل آمن ولا يتم تخزين كلمات المرور.
- **قاعدة بيانات:** يتم حفظ جميع البيانات في قاعدة بيانات SQLite لضمان عدم فقدانها.

## كيفية التثبيت والإعداد

1.  **استنساخ المستودع:**
    ```bash
    git clone <repository_url>
    cd <repository_directory>
    ```

2.  **تثبيت الاعتماديات:**
    تأكد من وجود Python 3.8+ مثبت على نظامك. ثم قم بتشغيل الأمر التالي:
    ```bash
    pip install -r requirements.txt
    ```

3.  **الحصول على بيانات تيليجرام:**
    -   اذهب إلى [my.telegram.org](https://my.telegram.org) وقم بتسجيل الدخول.
    -   اذهب إلى "API development tools" وقم بإنشاء تطبيق جديد.
    -   ستحصل على `api_id` و `api_hash`.

4.  **الحصول على توكن البوت:**
    -   تحدث إلى [@BotFather](https://t.me/BotFather) على تيليجرام.
    -   قم بإنشاء بوت جديد باستخدام الأمر `/newbot`.
    -   ستحصل على توكن (رمز) البوت.

5.  **تعديل ملف الإعدادات:**
    -   افتح ملف `config.ini`.
    -   ضع `api_id`, `api_hash`, و `bot_token` التي حصلت عليها في الخطوات السابقة.
    ```ini
    [telegram]
    api_id = YOUR_API_ID
    api_hash = YOUR_API_HASH

    [bot]
    bot_token = YOUR_BOT_TOKEN
    ```

## كيفية التشغيل

بعد إكمال خطوات الإعداد، قم بتشغيل البوت باستخدام الأمر التالي:
```bash
python3 main.py
```

الآن اذهب إلى بوتك على تيليجرام وابدأ باستخدامه!

## ملاحظات

- **الفاصل الزمني:** لتجنب حظر حسابك، تم تعيين فاصل زمني (60 ثانية) بين إنشاء كل مجموعة. يمكنك تعديل هذه القيمة في ملف `main.py` (المتغير `GROUP_CREATION_INTERVAL`).
- **الحد اليومي:** تم تعيين حد أقصى لإنشاء 50 مجموعة في اليوم لكل حساب. يمكنك تعديل هذه القيمة في ملف `main.py` (المتغير `MAX_GROUPS_PER_DAY`).
